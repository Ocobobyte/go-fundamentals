# Structs

## Declaring new Types in Go

Before you can start working with structs, you need to first understand how to declare new types in Go.

```go
package main

import "fmt"

type MyInt int
type MyString string
type MyMap map[string]string

func main() {
  i := MyInt(1)
  s := MyString("foo")
  m := MyMap{"foo": "bar"}

  fmt.Printf("%[1]T:\t%[1]v\n", i)
  fmt.Printf("%[1]T:\t%[1]v\n", s)
  fmt.Printf("%[1]T:\t%[1]v\n", m)
}

// main.MyInt:     1
// main.MyString:  foo
// main.MyMap:     map[foo:bar]
```

## Defining and Initializing a Struct

Structs provide you with a way to define complex types. Struct initialization is nearly identical to that of map initialization.

```go
type User struct {
  Name string
  Age  int
}

func main() {
  u := User{}

  fmt.Printf("%+v\n", u) // {Name: Age:0}
}
```

```go
type User struct {
  Name string
  Age  int
}

func main() {
  u := User{
    Name: "Jimi",
    Age: 27,
  }

  fmt.Printf("%+v\n", u) // {Name:Jimi Age:27}
}
```

## Initialization without Field Names

When initializing a struct with values, we have always used the field names to specify the values. This is required when using multiline initialization. when initializing a struct on a single line, the use of field names is optional.

```go
type User struct {
  Name string
  Age  int
}

func main() {
  u := User{"Kurt", 27}

  fmt.Printf("%+v\n", u) // {Name:Kurt Age:27}
}
```

When not using field names during initialization, all fields are required to be present.

```go
type User struct {
  Name string
  Age  int
}

func main() {
  u := User{"Kurt"}

  fmt.Printf("%+v\n", u)
}

// ./main.go:11:18: too few values in struct literal of type User
```

Finally, the order of the values must match how they are defined in the struct.

```go
type User struct {
  Name string
  Age  int
}

func main() {
  u := User{27, "Kurt"}

  fmt.Printf("%+v\n", u)
}

// ./main.go:11:12: cannot use 27 (untyped int constant) as string value in struct literal
// ./main.go:11:16: cannot use "Kurt" (untyped string constant) as int value in struct literal
```

## Accessing Struct Fields

Fields can be referenced using dot notation (a followed by the field name).

```go
type User struct {
  Name string
  Age  int
}

func printUser(u User) {
  name := u.Name
  age := u.Age

  fmt.Printf("%s is %d years old\n", name, age)
}

func main() {
  u := User{Age: 27}
  u.Name = "Janis"

  printUser(u)
}

// Janis is 27 years old
```

## Struct Tags

Struct tags are small pieces of metadata attached to fields of a struct that provide instructions to other Go code that works with the struct.

```go
type User struct {
  Name string `json:"name"`
}
```

## Using Struct Tags

A common use for struct tags is for encoding the data of your struct to some type of other format (JSON, XML).

```go
package main

import (
  "encoding/json"
  "log"
  "os"
)

type User struct {
  ID       int
  Name     string
  Phone    string
  Password string
}

func main() {
  u := User{
    ID: 1,
    Name: "Amy",
    Password: "goIsAwesome",
  }

  enc := json.NewEncoder(os.Stdout)

  if err := enc.Encode(u); err != nil {
    log.Fatal(err)
  }
}

// {"ID":1,"Name":"Amy","Phone":"","Password":"goIsAwesome"}
```

To allow us to control the JSON encoding for the `User` struct, the `encoding/json` package makes use of the *json* struct tag.

```go
type User struct {
  ID       int    `json:"id"`
  Name     string `json:"name"`
  Phone    string `json:"phone,omitempty"`
  Password string `json:"-"`
}

func main() {
  u := User{
    ID: 1,
    Name: "Amy",
    Password: "goIsAwesome",
  }

  enc := json.NewEncoder(os.Stdout)

  if err := enc.Encode(u); err != nil {
    log.Fatal(err)
  }
}

// {"id":1,"name":"Amy"}
```
